# IFC_notes · 中法学院学习资料 / Ressources d’étude

面向中法学院学生的课程学习与备考资料库，按 **专业 → 方向（如有） → semestre → 课程** 浏览。现有资料主要来自大三。法语下分 LF、LEA；金融保留方向层级，当前收录 Kedge-startup、marseille-management 两个方向。传播下分 LMC、Infocom。

Ce fonds de ressources, destiné aux étudiants de l’Institut franco-chinois, est organisé par **filière → parcours (le cas échéant) → semestre → cours**. Il concerne principalement la troisième année de licence. LF et LEA sont regroupés sous Français. La filière Finance conserve un niveau de parcours : les parcours actuellement représentés sont Kedge-startup et marseille-management. La filière Communication comprend LMC et Infocom.

## 使用说明 / Mode d’emploi

- S5、S6 表示本科第五、第六学期；`Semestre-a-confirmer` 表示学期待核对。
- 每个学期 README 提供课程目录、逐文件链接及归类依据。
- 金融下按方向分别维护；Kedge-startup 与 marseille-management 的课程、课表和通用资料分别保留在各自方向内。
- 当前登记 400 份资料，原有 335 份全部保留；压缩包按课程归档，未展开。重复文件和特殊格式未删除、未转换。代码与数据的课程内部相对路径保留。
- 本次只整理现有资料，不通过空目录宣称覆盖所有课程。

S5 et S6 désignent les cinquième et sixième semestres de licence. Les affectations non établies figurent dans `Semestre-a-confirmer`. Chaque README contient les cours, les liens vers les fichiers et les critères de classement. Les ressources de finance sont classées par parcours. Le fonds compte actuellement 400 fichiers de ressources ; les 335 fichiers initiaux sont conservés. Les archives restent non décompressées ; aucun doublon ni format particulier n’a été supprimé ou converti. Les chemins relatifs internes aux cours contenant du code et des données sont préservés. Ce classement ne prétend pas couvrir tous les enseignements.
