# 数学 / Mathématiques

[返回项目首页 / Accueil du projet](../README.md)

本目录按 semestre 和课程代码整理数学课程资料。S5、S6 为 Licence 3；S9（M1S1）、S10（M1S2）为 Master 1。课程内部保留原有的课程讲义、TD、TP、历年题、代码与数据层级，以避免破坏文件之间的相对路径。

Ce dossier rassemble les ressources de mathématiques par semestre et code d’UE. S5 et S6 correspondent à la L3 ; S9 (M1S1) et S10 (M1S2) au M1. Les sous-dossiers d’origine — cours, TD, TP, annales, code et données — sont conservés afin de préserver les chemins relatifs.

## 维护说明 / Mise à jour

新增资料请放入对应课程；若资料只可确认到学期，先放入该 semestre 下的待确认目录并注明来源。历年题、官方答案、学生笔记和代码／数据应保持区分。

Pour tout ajout, utiliser le dossier du cours concerné. Si seul le semestre est connu, créer un dossier temporaire à confirmer avec la provenance. Distinguer annales, corrigés officiels, notes étudiantes et code/données.
