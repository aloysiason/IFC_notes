# IFC_notes · 中法学院学习资料 / Ressources d’étude

面向中法学院学生的课程学习与备考资料库，按 **专业 → 方向（如有） → semestre → 课程** 浏览。现有资料主要来自大三。法语下分 LF、LEA；金融下收录 Kedge-startup、marseille-banque 两个方向。传播下分 LMC、Infocom。

Ce fonds de ressources, destiné aux étudiants de l’Institut franco-chinois, est organisé par **filière → parcours (le cas échéant) → semestre → cours**. Il concerne principalement la troisième année de licence. LF et LEA sont regroupés sous Français. En Finance, les parcours actuellement représentés sont Kedge-startup et marseille-banque. La filière Communication comprend LMC et Infocom.

## 写在前面

我们似乎正在进入一个知识越来越容易获得的时代。

过去，一份课程笔记、一条选课经验、一份考试资料，可能需要辗转几届学长学姐，经过许多次询问、摸索和试错才能得到。信息本身并不复杂，但获取信息的过程，常常消耗了我们大量的时间。

我们不禁想问：如果前人已经走过一段路，后来者是否还有必要从头走一遍？如果我们能够把这些经验留下来，是否就能把更多时间还给真正值得做的事情？

我们也想借此尝试打破某种信息上的壁垒。知识不应该成为少数人的隐秘资产，学习经验也不应该依附于某种偶然的关系网络。它们理应能够被分享、被检验、被补充，再被下一届人继续使用。

我们无法回答是否有必要接受法国的高等教育，也无法替每个人回答究竟应该如何度过大学。但至少，对于后一个问题，我们有一个朴素而坚定的答案：**我们需要时间。**

我们希望，这个小小的开源项目能够成为一种微不足道的起点。它不生产知识，只是试着把知识留下来；不替代学习，只是希望减少学习之前不必要的奔波。让学长学姐的经验不止于一次交谈，让学弟学妹的探索不必始于一片空白。

我们感谢每一位愿意分享资料、整理文件、补充经验和参与维护的人。今天你留下的一页笔记、一条注释，或许会在某个未来的下午，恰好帮助一个素不相识的人。

我们是后来者，也终将成为前人。

我们也想特别感谢清华大学计算机系等相关开源学习项目带给我们的启发。正是这些先行者的实践，让我们看到，学习资料可以不止于个人收藏，课程经验也可以超越年级与时间，在开放协作中不断积累和传递。

我们希望借鉴这样的开源理念，在中法学院尝试做一件类似的事情：从一点点资料开始，让更多人的经验被看见、被保存，也让后来者有机会站在前人的肩膀上继续前行。

**愿知识自由流动，愿时间有所归属。**
